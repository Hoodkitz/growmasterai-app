# Feature Vergleich: Web-App vs Mobile App

## ✅ Web-App (growmaster.app) - DAS ORIGINAL

### Core Features:
- 🎭 **Jay & Silent Bob Avatare** (GIF Animationen, Easter Eggs)
- 💡 **LED Hardware Steuerung** (Matrix S300/S600/S900/S1200)
- 🌈 **Spektrale Farbkodierung**:
  - Channel 1: Blau (#007AFF) - Vegetation
  - Channel 2: Rot (#FF3B30) - Blüte
  - Channel 3: UV (#BF5AF2) - Speziallicht
  - Channel 4: Full Spectrum (#FFD60A) - Natürliches Licht
- 📊 **Spectrum Lab** (Equalizer-Style Interface)
- ⚫ **True Black Dark Mode** (#000000) - Photoperioden-Schutz
- 📅 **Smart Calendar** mit Grow-Zyklen
- 🌡️ **VPD & DLI Rechner** (Professionelle Metriken)
- 🔧 **Hardware-Integration** (MQTT, WebSocket)
- 📈 **Analytics & Kosten-Tracking**
- 👥 **Team-Kollaboration** (Rollen-System)

### Design-Prinzipien:
- **Funktional**: Jedes Element hat einen biologischen/technischen Grund
- **Minimalistisch**: Fokus auf das Wesentliche
- **Professionell**: Für ernsthafte Grower
