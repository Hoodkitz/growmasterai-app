SCHRITT 3: Screenshots machen
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Option A - Emulator Screenshot Button:
1. Im Emulator-Fenster rechts: "..." (More) klicken
2. "Screenshot" wählen
3. Datei wird gespeichert

Option B - Windows Snipping Tool:
1. Windows + Shift + S
2. Bereich auswählen (nur Emulator-Screen)
3. Screenshot wird in Clipboard gespeichert
4. Einfügen in Paint/Editor → Speichern

Option C - Emulator Camera Button:
1. Rechte Sidebar im Emulator
2. Camera Icon klicken
3. Screenshot wird automatisch gespeichert

===============================================================================
METHODE 2: PHYSICAL DEVICE (Falls vorhanden)
===============================================================================

1. Installiere Development Build auf deinem Android Handy:
   npm start → Scan QR Code mit Expo Go

2. Öffne App auf dem Handy

3. Navigiere zu verschiedenen Screens

4. Mache Screenshots:
   - Power Button + Volume Down (gleichzeitig)
   - Screenshots → Gallery

5. Transfer zu PC:
   - USB Kabel
   - Oder: Google Photos
   - Oder: Email an dich selbst

===============================================================================
SCREENSHOT BEST PRACTICES
===============================================================================

✅ DO's:
• Zeige echte App-Features
• Nutze Dark Mode (sieht moderner aus)
• Zeige Daten/Pflanzen (nicht leere Screens)
• Alle Screenshots gleiche Auflösung
• High Quality (keine Blur)

❌ DON'Ts:
• Keine persönlichen Daten zeigen
• Keine Copyright-Bilder
• Keine zu kleinen Screenshots
• Keine unterschiedlichen Aspect Ratios
• Kein Lorem Ipsum Text

UPLOAD ZU GOOGLE PLAY
===============================================================================

Google Play Console → Store presence → Main store listing
→ Scrolle zu "Graphics"
→ "Phone screenshots"
→ Upload/Drag & Drop

Reihenfolge wichtig!
1. Screenshot = Wird als erstes angezeigt im Store
→ Wähle deinen besten Screenshot (z.B. Plant Doctor)


===============================================================================
TROUBLESHOOTING
===============================================================================

Problem: "Emulator startet nicht"
→ Lösung: Android Studio → AVD Manager → Cold Boot

Problem: "Screenshots zu klein"
→ Lösung: Vergrößere Emulator-Fenster vor Screenshot

Problem: "Screenshots haben verschiedene Größen"
→ Lösung: Resize alle auf gleiche Größe mit:
  https://www.iloveimg.com/resize-image

Problem: "App sieht leer aus"
→ Lösung: Füge Test-Daten hinzu (Pflanzen, Journal-Einträge)
