# 🎨 App Assets Creation Guide

## Quick Assets Checklist

**REQUIRED for Launch:**
- [ ] App Icon (1024x1024)
- [ ] Screenshots (5-8 per platform)
- [ ] Feature Graphic (Android only, 1024x500)

**OPTIONAL (but recommended):**
- [ ] App Preview Video (15-30 seconds)
- [ ] Marketing banners

---

## 1. App Icon (CRITICAL - 30 minutes)

### Requirements:
- **Size:** 1024x1024 pixels
- **Format:** PNG, no transparency
- **Style:** Simple, recognizable, on-brand

### Design Concept: Cannabis Leaf + AI Brain

**Option 1: Minimalist Leaf**
```
Green cannabis leaf silhouette
Simple, clean lines
Solid green (#10B981)
White background
```

**Option 2: Leaf + Tech**
```
Cannabis leaf with circuit lines
Represents: Nature + Technology
Green gradient
Modern, tech-forward
```

**Option 3: Text + Icon**
```
"GM" letters (GrowMaster)
Cannabis leaf integrated
Bold, memorable
Easy to recognize
```

### Quick Creation Tools:

**Free/Easy:**
1. **Canva** (https://canva.com)
   - Use "App Icon" template
   - Search "cannabis leaf" or "plant"
   - Add your style
   - Export as PNG

2. **Figma** (https://figma.com)
   - Professional tool
   - Free tier available
   - Vector-based

3. **Online Icon Makers:**
   - https://icon.kitchen/
   - https://appicon.co/
   - Upload logo → generates all sizes

### DIY Instructions:

1. Find a cannabis leaf SVG (free on sites like flaticon.com)
2. Open in Canva/Figma
3. Set canvas to 1024x1024
4. Place leaf in center
5. Add green gradient background
6. Optional: Add "AI" badge in corner
7. Export as PNG

### Professional Option ($5-50):
- Fiverr: Search "app icon design"
- 99designs: Icon design contest
- Upwork: Hire designer for 1 hour

---

## 2. Screenshots (IMPORTANT - 2 hours)

### Required Sizes:

**iOS:**
- 6.5" Display (1284 x 2778) - iPhone 14 Pro Max
- 5.5" Display (1242 x 2208) - iPhone 8 Plus  
- 12.9" Display (2048 x 2732) - iPad Pro

**Android:**
- Phone (1080 x 1920 minimum)
- 7" Tablet (1200 x 1920) - optional

### Content Strategy:

**Screenshot 1: AI Diagnosis**
- Show: Plant photo + diagnosis result
- Text: "Instant AI Plant Diagnosis"
- Highlight: 90% accuracy

**Screenshot 2: Grow Journal**
- Show: Beautiful timeline with photos
- Text: "Track Your Entire Grow"
- Highlight: Photo timeline

**Screenshot 3: AI Coach**
- Show: Chat interface with helpful response
- Text: "24/7 Expert Advice"
- Highlight: Personalized tips

**Screenshot 4: Smart Reminders**
- Show: Notification + reminder list
- Text: "Never Forget Watering"
- Highlight: Auto reminders

**Screenshot 5: Community**
- Show: Feed with beautiful plant photos
- Text: "Join 100k+ Growers"
- Highlight: Community support

**Optional Screenshot 6: Marketplace**
- Show: Product listings
- Text: "Shop Quality Supplies"

**Optional Screenshot 7: Yield Prediction**
- Show: Prediction calculator
- Text: "Know What to Expect"

**Optional Screenshot 8: Cost Tracking**
- Show: Expense breakdown
- Text: "Track Your ROI"

### How to Create:

**Method 1: Real Screenshots + Text Overlay**

1. **Take Screenshots:**
   ```bash
   # Run app in simulator
   npx expo start
   # Press 'i' for iOS or 'a' for Android
   # Navigate to each screen
   # Take screenshots (Cmd+S on iOS Simulator)
   ```

2. **Add Text Overlay in Canva:**
   - Upload screenshot
   - Add text overlay at top
   - Add short description at bottom
   - Use app colors (#10B981)
   - Export in correct size

**Method 2: Design Tool**
- Use Figma/Sketch
- Create mockup frames
- Add screenshots
- Add marketing text
- Export

**Method 3: Screenshot Tools**
- https://www.screely.com/ (free)
- https://screenshots.pro/ (paid)
- https://hotpot.ai/mockup (free)

### Quick Template:

```
[Top 20%: Large Text]
"Instant AI Plant Diagnosis"

[Middle 60%: Screenshot]
[Actual app screenshot here]

[Bottom 20%: Subtitle]
"Take a photo, get expert diagnosis in seconds"
```

## 3. Feature Graphic (Android Only - 30 minutes)

### Requirements:
- **Size:** 1024 x 500 pixels
- **Format:** PNG or JPG
- **Purpose:** Featured banner in Play Store

### Content:
- App name: "GrowMaster AI"
- Tagline: "AI-Powered Cannabis Growing"
- Hero image: Beautiful cannabis plant
- Call to action: "Grow Like a Pro"

### Quick Creation:
1. Canva → "Google Play Feature Graphic" template
2. Add background image (cannabis plant)
3. Add text overlay
4. Use app colors
5. Export as PNG

## 4. App Preview Video (OPTIONAL - 1-2 hours)

### Specifications:
- **Length:** 15-30 seconds
- **Resolution:** 1080p (1920x1080)
- **Format:** MP4
- **Sound:** Optional but recommended

### Script (30 seconds):

```
0-5s:   App logo animation + name
        "GrowMaster AI"

5-10s:  AI Diagnosis feature
        "Instant Problem Detection"
        [Show photo → diagnosis]

10-15s: AI Coach
        "Expert Advice 24/7"
        [Show chat interaction]

15-20s: Grow Journal
        "Track Your Entire Grow"
        [Show timeline]

20-25s: Smart Reminders
        "Never Forget Watering"
        [Show notification]

25-30s: Call to Action
        "Download Now"
        [App icon + stores]
```

### How to Create:

**Option 1: Screen Recording**
```bash
# iOS Simulator
cmd + R to start recording
Navigate through app
Stop recording
Edit in iMovie/Final Cut
```

**Option 2: Hire on Fiverr ($20-100)**
- Search "app preview video"
- Send screenshots + script
- Get professional video

**Option 3: Online Tools**
- https://www.renderforest.com/
- https://www.animaker.com/
- Upload screenshots, auto-generates video
